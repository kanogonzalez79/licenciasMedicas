# Inicio

Es la primera pantalla que se ve al abrir el sistema. Es una pantalla de bienvenida, sin datos ni formularios: solo resume en una tarjeta los cuatro accesos que más se usan en el día a día, con una frase de una línea explicando para qué sirve cada uno.

![Pantalla de inicio del sistema, con la tarjeta de accesos rápidos](01-vista-general.png)

Desde aquí no se realiza ninguna acción — su único propósito es orientar a quien recién abre la aplicación hacia el menú lateral, donde están todas las pantallas reales del sistema (ver el resto de este manual).
