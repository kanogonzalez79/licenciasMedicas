# Glosario de términos

**Archivo (carpeta de archivo)**
: El destino final de los documentos ya grabados de forma permanente, organizado en subcarpetas por año y mes. Cada documento se nombra como `{Nombre del paciente en Título Case} - {Folio}` seguido de su extensión.

**Correo enviado (marca por licencia)**
: Indicador individual de cada licencia que señala si su aviso ya fue enviado (por el sistema o por fuera de él). Es independiente del registro de "se envió el correo de tal unidad en tal fecha": una licencia marcada como correo enviado queda excluida de cualquier aviso futuro para su unidad y fecha, sin importar cuándo se grabó.

**DV (dígito verificador)**
: El último carácter del RUT chileno, que permite comprobar matemáticamente (con el algoritmo módulo 11) que el número no tiene un error de digitación. El sistema rechaza cualquier RUT cuyo dígito verificador no calce, tanto para pacientes como para profesionales. El RUT se acepta con o sin puntos y con o sin guion.

**Folio**
: El identificador único de una licencia en todo el sistema. Nunca se permite un folio duplicado, ni siquiera entre una licencia ya grabada y una pendiente de revisión.

**Incoming**
: La carpeta donde se depositan los PDF nuevos, antes de ser leídos por el sistema.

**Staging (revisión)**
: La carpeta y el estado intermedio de un PDF ya leído, pero todavía pendiente de confirmar con "Grabar" o de descartar.

**Tipo de formulario**
: Indica el origen del documento de una licencia: "Formulario tipo 1" o "Formulario tipo 2" (leídos automáticamente por el sistema) o "Manual" (tipeada a mano). No debe confundirse con el tipo de licencia.

**Tipo de licencia**
: El código médico (1 a 7) que indica el motivo del reposo, definido por la normativa vigente: 1 Enfermedad o Accidente Común, 2 Prórroga Medicina Preventiva, 3 Licencia Maternal Pre y Post Natal, 4 Enfermedad Grave Hijo Menor de 1 Año, 5 Accidente del Trabajo o del Trayecto, 6 Enfermedad Profesional, 7 Patología del Embarazo.

**Unidad**
: El área o departamento organizacional al que se asigna una licencia, con un correo de contacto propio para recibir sus avisos.
